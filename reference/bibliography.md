# References to all the datasets included in this package.

This is a
[`RefManageR::BibEntry()`](https://docs.ropensci.org/RefManageR/reference/BibEntry.html)
object that can be manipulated using the
[RefManageR::RefManageR](https://docs.ropensci.org/RefManageR/reference/RefManageR-package.html)
package functions or the standard citation functions in R.

## Usage

``` r
bibliography
```

## Format

An object of class `BibEntry` (inherits from `bibentry`) of length 70.
