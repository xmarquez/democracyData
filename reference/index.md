## Generate\_ functions

Functions for generating other democracy datasets.

- [`generate_democracy_scores_dataset()`](https://xmarquez.github.io/democracyData/reference/generate_democracy_scores_dataset.md)
  : Generate a data frame containing all the democracy measures
  accessible from this package
- [`generate_extended_uds()`](https://xmarquez.github.io/democracyData/reference/generate_extended_uds.md)
  : Generates the extended UDS scores from the latest democracy data in
  this package

## Latent Variable Models functions

Functions for producing latent variable models of democracy.

- [`prepare_democracy_data()`](https://xmarquez.github.io/democracyData/reference/prepare_democracy_data.md)
  : Prepare democracy data before replicating the UDS model
- [`prob_more()`](https://xmarquez.github.io/democracyData/reference/prob_more.md)
  : Probability that a country-year is more democratic than another
- [`democracy_scores()`](https://xmarquez.github.io/democracyData/reference/democracy_scores.md)
  : Extract UD scores from a UD model
- [`cutpoints()`](https://xmarquez.github.io/democracyData/reference/cutpoints.md)
  : Extract cutpoints from a UD model in a tidy format.
- [`raterinfo()`](https://xmarquez.github.io/democracyData/reference/raterinfo.md)
  : Extract rater info from a UD model in a tidy format.
