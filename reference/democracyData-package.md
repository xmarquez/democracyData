# democracyData: Access and Manipulate Most Available Democracy Datasets

Archives a large number of democracy datasets, many of historical
interest. It also provides a number of functions to download these
datasets (where available) and determine membership of a country in
standard membership lists of the state system (according to Gleditsch
and Ward, Correlates of War, or Polity).
